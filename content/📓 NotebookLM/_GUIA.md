## 🔥 Preguntas Universales (para CUALQUIER cuaderno)

### 1. Ideas Principales
```
¿Cuáles son las 5-10 ideas principales de todo el contenido de este cuaderno?
Organízalas de más a menos importante para alguien que quiere crear contenido en YouTube sobre desarrollo personal y marca personal.
```

### 2. Frases Cortas para Hooks
```
Extrae 15-20 frases cortas, potentes y memorables del contenido que puedan usarse como:
- Hooks para vídeos de YouTube
- Cierres de vídeos
- Frases para miniaturas
- Títulos de vídeos

Formato: una frase por línea, indicando de qué vídeo/autor viene.
```

### 3. Conexiones con Autores/Filósofos
```
¿Qué filósofos, autores o pensadores han dicho ideas similares a las principales de este contenido?
Para cada idea principal, sugiere:
- Un autor que la refuerza (con cita si es posible)
- Un autor que la contradice (con argumento)
- Cómo conectar esto con Camus, Kierkegaard, Séneca, Fromm, Byung-Chul Han, Nietzsche, Frankl
```

### 4. Contraargumentos (Idea Compass)
```
¿Qué argumentos en contra podrían hacerse a las ideas principales de este contenido?
¿Quién estaría en desacuerdo y por qué?
¿Qué diría un crítico de estas ideas?
Organiza por tema: argumento a favor | argumento en contra | posible respuesta
```

### 5. Estructura de Guión
```
Organiza las ideas más poderosas de este contenido en una estructura de guión para un vídeo de YouTube de 8-10 minutos:
- GANCHO (0-30s): frase impactante o pregunta incómoda
- VALIDACIÓN (30s-2min): conectar con el dolor del espectador
- DESARROLLO (2-6min): argumentos + ejemplos + datos
- METÁFORAS (6-7min): hacer tangible lo abstracto
- DESAFÍO (7-9min): retar al espectador a actuar
- CIERRE (9-10min): frase que se quede grabada
```

### 6. Flashcards de Aprendizaje
```
Genera 40-50 preguntas de estudio basadas en el contenido de este cuaderno.
Formato: Pregunta | Respuesta detallada (con contexto, ejemplo y aplicación práctica)
Enfócate en conceptos que Daniel pueda usar en sus vídeos o en su estrategia de marca.
```

### 7. Aplicación a Marca Personal
```
Basándote en todo el contenido de este cuaderno, ¿cómo aplicaría [autor] los siguientes conceptos a la marca personal de un creador de contenido de 26 años que:
- Viene del mundo del deporte (porteros)
- Está reinventándose en el nicho de motivación/desarrollo personal
- Tiene una audiencia de 18-35 años frustrados con el sistema
- Quiere monetizar con formación
- Habla con lenguaje directo, tacos, vulnerabilidad

Dame 10 acciones concretas con ejemplos específicos.
```

### 8. Datos y Estadísticas
```
Extrae todos los datos, estadísticas, porcentajes y hechos concretos mencionados en el contenido.
Organízalo por tema. Incluye la fuente si se menciona.
```

### 9. Frameworks y Modelos
```
¿Qué frameworks, modelos o sistemas propone [autor] en su contenido?
Para cada uno explica:
- Qué es
- Cómo funciona
- Ejemplo práctico
- Cómo podría usarlo Daniel en sus vídeos
```

### 10. Lo que Nadie Dice
```
¿Qué ideas incómodas, contraintuitivas o políticamente incorrectas menciona [autor]?
¿Qué dice que otros creadores no se atreven a decir?
Organízalo por tema con la cita textual si es posible.
```
