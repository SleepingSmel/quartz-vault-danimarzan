## PARTE 6: GOOGLE PLACES API — CÓMO ACCEDER A DATOS DE GOOGLE MAPS

### Opción A: Google Places API (oficial, de pago)

**Cómo configurarla (tú lo haces):**

1. Ve a **console.cloud.google.com**
2. Crea un proyecto nuevo
3. Habilita "Places API"
4. Crea una API key
5. Configura facturación (tienes $200/mes gratis)
6. Me das la API key a mí

**Coste:**
- $200/mes gratis (crédito inicial)
- Después: ~$5-10 por cada 1000 búsquedas
- Para 1000 negocios: ~$5-10/mes

**Qué datos obtienes:**
- Nombre del negocio
- Dirección
- Teléfono
- Website
- Rating y reseñas
- Horarios
- Fotos
- Categoría

**Limitación:** NO incluye email (tienes que buscarlo en su web)

### Opción B: Outscraper (más fácil, gratis para empezar)

**Cómo configurarla (tú lo haces):**

1. Ve a **outscraper.com**
2. Crea cuenta gratuita
3. Selecciona "Google Maps Scraper"
4. Busca por categoría y ubicación
5. Exporta a CSV
6. Me pasas el CSV a mí

**Coste:**
- Gratis: 500 registros/mes
- De pago: desde $29/mes para más

**Qué datos obtienes:**
- Todo lo de Google Places API
- **MÁS:** Email (si está en la web del negocio)
- Redes sociales (si están en el perfil de Google)

### Opción C: Yo busco con Firecrawl (lo hago yo, gratis)

**Qué puedo hacer:**
- Buscar en Google "restaurants in [ciudad]" → Encuentra negocios
- Entrar a cada web → Extraer email, teléfono, redes
- Analizar su presencia online → Clasificar por prioridad

**Limitación:** Más lento que una API, pero funciona
